# Dinboard — конструктор электрощитов

## Суть
Бесплатный открытый веб-конструктор электрических щитов для электриков-монтажников (а также домашних мастеров и заказчиков). Пользователь выбирает на сайте корпус щита популярного производителя, расставляет модульное оборудование по DIN-рейкам и видит визуальную схему, максимально близкую к реальному щиту, со спецификацией собранного.

Работает в браузере, без регистрации, публикуется на GitHub Pages.

- Производители на старте: ABB, Schneider Electric, Hager, Legrand, Eaton.
- Языки интерфейса: русский (основной), литовский, английский.
- Цены не ведём (возможно, позже).
- Ближайшая цель — ядро конструктора. Выгрузки (PDF, CSV, Excel) и дополнительные функции — после ядра (см. `PLAN.md`).

## Стек
- HTML, CSS, JavaScript (нативные ES-модули) без сборки и фреймворков.
- Каталог оборудования — статичные JSON-файлы в репозитории (`site/data/`).
- Визуализация щита — SVG.
- Хранение у пользователя — localStorage, ссылка с данными сборки, файл проекта `.json`.
- Тесты — встроенный `node --test` (Node.js 22+, локально v26; в CI проверяются 22 и 26).
- `package.json` без зависимостей: только `"type": "module"`, `engines` и команды.
- Публикация — GitHub Pages через GitHub Actions (публикуется только папка `site/`).

## Не используем
- Фреймворки и сборщики (React, Vue, Vite, webpack) — лишняя сложность, сайт должен работать как есть. Вместо них нативные ES-модули.
- Сервер и базу данных — GitHub Pages отдаёт только статику. Вместо них JSON-каталог и хранилище браузера. (Сервер на Node для редактора каталога возможен в будущем, отдельным решением.)
- npm-зависимости и сторонние библиотеки — только с отдельного разрешения.
- Фото, логотипы и изображения с сайтов производителей — авторские права. Вместо них собственная SVG-отрисовка. Названия брендов, серий и артикулы использовать можно.

## Команды
- Локальный запуск: `npm start` (= `node tools/serve.js`), затем открыть http://localhost:8080. Порт меняется переменной `PORT`. Остановка — Ctrl+C.
- Тесты: `npm test` (= `node --test "tests/**/*.test.js"`; glob вместо папки, потому что Node 22 не раскрывает папку в `--test`).
- Сборка: не требуется.
- Линтер: нет (проверь: нужен ли).

## Особенности проекта
- Пользовательских рабочих данных у проекта нет: сборки пользователей хранятся у них в браузерах. Каталог `site/data/` — данные проекта, меняем их только в рамках этапа.
- Данные каталога (артикулы, ширина в модулях, размеры и количество рядов корпусов) берутся из официальных каталогов производителей. Непроверенные позиции помечаются полем `"verified": false`.
- Логика (каталог, модель щита, расчёты) — в модулях без обращения к DOM, чтобы их можно было тестировать через `node --test`.
- Интерфейс проверять вручную в браузере через локальный сервер, включая ширину телефона. Сервер после проверки останавливать.
- Все тексты интерфейса — через файлы переводов (ru, lt, en), без строк прямо в коде. Исключения в `site/index.html`: название «Dinboard» (не переводится) и строка `<noscript>` сразу на трёх языках (она видна, когда JavaScript и переводы не работают).
- Коммиты на русском (проверь).

## Для ревью
- Расчёт модулей и рядов корректен для всех корпусов каталога.
- Данные из URL, файла проекта и localStorage проверяются перед использованием и не вставляются в страницу как HTML.
- Каталог проходит проверку схемы (тест).
- В `site/` нет ничего, кроме файлов сайта.
